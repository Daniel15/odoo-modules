This module adds a "Save for Later" button to surveys, allowing users to
save their progress and resume at a later time.

When clicked, the current answers are saved without validation
(mandatory questions can be skipped), and the user receives a link to
resume the survey. If the user has provided an email address, they also
receive an email with the resume link.

## Key Features

- Save survey progress at any point without validation
- Email with resume link sent to users who have provided an email
- Resume link displayed in modal for immediate reference
- All answers are preserved and restored when resuming
- Chatter message logged when save-for-later email is sent
- Configurable per survey (can be disabled on surveys where not needed)
