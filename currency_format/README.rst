This module makes the spacing between a currency symbol and its amount
configurable per currency. It combines symbol position and spacing into
one Display Format field with four choices: ``$123.45``, ``$ 123.45``,
``123.45$``, and ``123.45 $``.

On installation, the spacing for existing currencies will be set based
on their default CLDR-derived configuration.

Configuration
=============

The module sets useful defaults, but you can change the settings for any
currency. Enable developer mode, go to **Settings → Currencies**, click
a currency, then select the desired **Display Format**.
